## 实现要点

1. **手工编写**：按 PRD 要求手工对照源码编写，每个端点的参数名、类型、默认值、约束均来自路由源码
2. **Components 复用**：定义了 `InputMode`、`OkResponse`、`ErrorResponse`、`PublishPlatform` 等可复用 schema，以及 `BadRequest`/`NotFound` 通用响应
3. **示例完整**：每个 operation 至少包含 1 个完整的请求/响应示例
4. **轻量路由**：`/api/docs/publish` 直接 send_file 返回 YAML，不引入 Swagger UI
5. **路径计算**：`_DOCS_DIR` 使用模块相对路径计算，不依赖运行时 CWD
