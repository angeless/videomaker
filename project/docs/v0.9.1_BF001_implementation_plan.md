# BF-001 实施计划：修复 386 个 PermissionError 测试错误

**任务编号**: BF-001 (Bug Fix)
**版本**: v0.9.1
**日期**: 2026-03-20

---

## 当前代码现状理解

- 全量测试结果：411 passed, 7 failed, 386 errors
- 386 个 error 全部为同一根因：`PermissionError: [Errno 1] Operation not permitted: '/Users/angelwang/Downloads/语义数据库-chatgpt-20260306/semantic_keyword_library_flat.jsonl'`
- 根因：`modules/library/global_media_library.py` 第 289 行硬编码了 `~/Downloads/语义数据库-chatgpt-20260306` 路径
- `_seed_tag_library_if_empty()` 方法第 849 行用 `Path.exists()` 检查文件是否存在，但在 macOS TCC (Transparency, Consent, and Control) 安全机制下，`~/Downloads` 目录的文件 metadata 可读（`exists()` 返回 True），但文件内容不可读（`open()` 抛出 PermissionError）
- 影响 16 个测试文件，其中 2 个（`test_semantic_system.py`, `test_tag_recall.py`）有自己的 `_SEED_DIR.exists()` skipif 条件，同样被 TCC 绕过

## 本轮实施计划

1. 在 `global_media_library.py` 的 `_seed_tag_library_if_empty()` 中，在 `exists()` 检查之后增加实际可读性检查（`try open/close`），PermissionError 时静默 return
2. 在 `test_semantic_system.py` 和 `test_tag_recall.py` 中，将 skipif 条件从 `_SEED_DIR.exists()` 改为实际文件可读性检查

## 预计修改文件清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `modules/library/global_media_library.py` | 修改 | 在 `_seed_tag_library_if_empty()` 增加 TCC PermissionError 防护 |
| `tests/test_semantic_system.py` | 修改 | skipif 条件改为文件可读性检查 |
| `tests/test_tag_recall.py` | 修改 | skipif 条件改为文件可读性检查 |

## 实现约束

- 不修改 seed 数据的导入逻辑
- 不修改 `_SEED_DATA_DIR` 的路径配置
- 不修改任何已有 API 或公共接口
- 改动最小化：只加防护，不做重构
