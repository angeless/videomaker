## 三、阻断项详情（4 项）

### 阻断 B1：R6b 缺少"输入"字段

计划在涉及文件之后直接给出"WAL 行格式"，未设 `**输入**` 标记行。§3.3 明确要求输入为必填字段（Dict 类型）。

**补充内容（插入到涉及文件与 WAL行格式 之间）**：

```
**输入**：`add_batch(uid_vec_pairs: List[Tuple[str, np.ndarray]])` 调用时，每个 `(uid, vec)` 对作为一条 WAL 记录写入
```

---

### 阻断 B2：R6c 缺少"输入"字段

计划从涉及文件直接跳到"可用模型（2 个）"，无 `**输入**` 字段。

**补充内容**：

```
**输入**：`POST /api/settings/clip-model { "model_id": "openai/clip-vit-large-patch14" }`；
或修改配置文件 DEFAULT_CLIP_MODEL 值后重启
```

---

### 阻断 B3：R10 缺少"输入"和"输出"字段

计划有 LUT 预设名和分级磨皮强度比，但均非正式的输入/输出字段，违反 §3.3 两项必填要求。

**补充内容（插入到涉及文件与 LUT预设 之间）**：

```
**输入**：`POST /api/beauty/preview { "frame_base64": "<base64>", "beauty_params": {
  "lut": "outdoor_natural" | null,
  "smooth_level": 0.0~1.0,
  "region_graded": true | false
}}`

**输出**：
- `POST /api/beauty/preview` → `{ "result_base64": "...", "processing_ms": int }`
- `GET /api/beauty/lut-presets` → `["outdoor_natural", "indoor_warm", "food", "night", "travel"]`
- `modules/step7_final_render/luts/*.cube` — 5 个新增 LUT 文件
```

---

### 阻断 B4：R12 缺少"输入"和"输出"字段

R12 集成测试任务无输入/输出定义，直接给出验收矩阵，违反 §3.3 两项必填要求。

**补充内容（插入到涉及文件与验收矩阵之间）**：

```
**输入**：R1~R11 全部标记完成；执行 `bash scripts/ci_verify.sh` 触发集成验证流程

**输出**：
- `project/docs/test-reports/2026-xx-xx-v0.13-test-report.md`（Create）
- `project/docs/audit/2026-xx-xx-v0.13-final-audit.md`（Create）
- `project/CHANGELOG.md` — [未发布] → [0.13.0]
- `project/VERSION` → `0.13.0`
```
