## 6. 审计发现 (Issues)

### Issue #1: RoughCutView.vue 渲染冗余 (LOW)

**位置：** `RoughCutView.vue:58-83`

**问题：** 当 `videoType === 'speech'` 或 `videoType === 'scenic'` 时，同时渲染 `rc-workspace` 中的条件面板和 `rc-panel-full` 中的同一组件，导致组件可能被双重挂载。

**详细分析：**
- `v-if="store.videoType !== 'scenic'"` → speech 时显示 TranscriptEditor
- `v-if="store.videoType === 'speech'"` → 又在 rc-panel-full 中显示 TranscriptEditor

当 videoType='speech' 时，两个 TranscriptEditor 都会挂载。

**影响：** 低 — 实际布局上一个在 flex 容器中，一个在 full 容器中，视觉上可能重叠或重复。

**建议修复：** 使用 `v-else-if` 链或明确互斥条件。

**优先级：** LOW — 不影响功能，但影响性能和 DOM 整洁。

### Issue #2: FillerMark.word_indices 属性缺失 (MEDIUM)

**位置：** `contracts.py:42` + `roughcut_routes.py:206` + `TranscriptEditor.vue:78`

**问题：** FillerMark dataclass 没有 `word_indices` 字段（只有 `word_idx: int`），但 API 序列化时使用 `fm.word_indices`，前端也期望 `f.word_indices` 数组。

**详细分析：**
- `contracts.py` FillerMark 定义: `word_idx: int` (单个索引)
- `roughcut_routes.py:206`: `"word_indices": fm.word_indices` — 访问不存在的属性
- `TranscriptEditor.vue:78`: `for (const wi of (f.word_indices || []))` — 期望数组

**影响：** MEDIUM — API `/api/roughcut/{id}/fillers` 调用时会报 AttributeError。但由于当前前端先调用 `loadFillers` 且未集成真实转录，实际场景未触发。

**建议修复：** 在 FillerMark 中添加 `word_indices: List[int] = field(default_factory=list)` 字段，或修改 API 序列化为 `[fm.word_idx]`。

**优先级：** MEDIUM — 潜在运行时错误，需修复。

### Issue #3: roughcut_routes generate 状态未恢复 (LOW)

**位置：** `roughcut.js:184-193`

**问题：** `generateRoughCut` 成功时不设 `status.value = 'ready'`，保持 `rendering` 状态。需要用户手动操作才能退出渲染状态。

**影响：** LOW — 当前 generate 返回 202 (queued)，前端实际无轮询机制，UI 会卡在 "渲染中..."。

**建议修复：** 成功返回后设 `status.value = 'ready'`。

**优先级：** LOW — v0.15.0 将实现完整的 job polling。
