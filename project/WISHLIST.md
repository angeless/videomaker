# VideoEditor — 衍生建议与改进愿望清单

> 本文件收集开发过程中发现的计划外改进机会。
> 仅记录，不执行。纳入正式开发计划后方可执行。
> Phase 7 衍生建议检查时追加到本文件。

## 格式说明

每条建议包含：
- **ID**: W-NNN（自增编号）
- **来源**: 发现于哪个版本/任务
- **描述**: 改进内容
- **优先级**: 高 / 中 / 低
- **状态**: 待评估 / 已纳入计划(vX.Y) / 已拒绝(原因)
