# 素材质量评分体系 — 详细设计 v2

**文档日期：** 2026-03-18
**基于代码版本：** 当前 main 分支
**对接模块：** `video_asset_toolkit.py` / `audio_quality.py` / `global_media_library.py`

---

## 一、现有基础盘点

通过代码审计，确认当前系统已有的评分基础：

| 模块 | 已实现指标 | 输出 | 位置 |
|------|-----------|------|------|
| audio_quality.py | SNR(35%), 噪底(20%), 响度LUFS(20%), 削波(15%), 余量(10%) | 0-1 score + quality_level | `audio_quality_info` |
| video_asset_toolkit.py | 分辨率评分(4K=0.95→<480p=0.30), 码率评分 | 0-1 score + quality_tier | `quality_score` |
| video_asset_toolkit.py | brightness, saturation, edge_density, motion_score, face_ratio, color_temp, texture_complexity | 原始数值 | `visual_stats` |
| global_media_library.py | narrative_role (atmospheric_broll/hero_shot/general_broll) | 字符串分类 | `analysis_json` |
| global_media_library.py | duration_bucket, quality_tier, mood, scene_description | 多种类型 | `analysis_json.semantic` |
| fingerprint.py | pHash + Hamming距离 ≤5 = 相似 | 64-bit hex | `video_fingerprints` |

**核心缺口：**
1. 没有美感/构图评分 — `visual_stats` 有原始数据但没有组合成美感评分
2. 没有叙事价值评分 — narrative_role 只有三档粗分类
3. 没有综合可用性评分 — 各维度分散存储，无汇总
4. 没有垃圾素材判定逻辑 — 无标记机制
5. 空镜/B-roll 分类规则过于简单 — 只看 edge_density + green/blue 比例

---

## 二、细化评分体系：七维模型

将原来提议的五维升级为七维，更精细地覆盖素材可用性的各个方面。

```
综合可用性评分 (usability_score) =
    技术质量    (tech_score)         × 0.15
  + 画面美感    (aesthetic_score)     × 0.20
  + 音频质量    (audio_score)        × 0.12
  + 叙事价值    (narrative_score)     × 0.18
  + 独特性      (uniqueness_score)   × 0.08
  + 编辑适用性  (edit_fitness_score)  × 0.15
  + 内容丰富度  (content_richness)   × 0.12
```

为什么是这个权重分配：美感和叙事价值权重最高（合计38%），因为用户的核心问题就是"好不好看"和"有没有用"；技术质量和编辑适用性次之（合计30%），保证素材可用；音频和内容丰富度再次（合计24%）；独特性最低（8%）因为它更多是锦上添花。

## 三、各维度详细计算公式

### 3.1 技术质量 (tech_score) — 权重 15%

**直接复用现有逻辑**，但增加两个子项：

```python
def compute_tech_score(asset_info, visual_stats):
    # 已有
    resolution_score = existing_resolution_score(asset_info)  # 4K=0.95 ... <480p=0.30
    bitrate_score = existing_bitrate_score(asset_info)        # >10M=0.95 ... <1M=0.30

    # 新增：稳定性评分
    # 基于 motion_score 的帧间方差
    # motion_score 来自 visual_stats，单位 0-255
    motion = visual_stats.get('motion_score', 0)
    if motion < 3:
        stability_score = 0.95    # 极稳（三脚架/固定）
    elif motion < 8:
        stability_score = 0.85    # 稳定（手持稳定器）
    elif motion < 15:
        stability_score = 0.70    # 轻微晃动
    elif motion < 25:
        stability_score = 0.50    # 明显晃动
    else:
        stability_score = 0.30    # 严重抖动

    # 新增：清晰度评分
    # 基于 edge_density 推断（暂无拉普拉斯方差）
    # edge_density 高 + texture_complexity 适中 = 清晰
    edge = visual_stats.get('edge_density', 0)
    texture = visual_stats.get('texture_complexity', 0)
    if edge >= 0.08 and texture >= 0.10:
        sharpness_score = 0.90
    elif edge >= 0.05:
        sharpness_score = 0.70
    elif edge >= 0.03:
        sharpness_score = 0.50
    else:
        sharpness_score = 0.30    # 可能模糊

    return (
        resolution_score * 0.30
      + bitrate_score    * 0.25
      + stability_score  * 0.25
      + sharpness_score  * 0.20
    )
```

**新增子维度说明：**

| 子指标 | 数据来源 | 计算方式 | 为什么需要 |
|--------|---------|---------|-----------|
| 稳定性 | `visual_stats.motion_score` | 帧差均值 → 阈值映射 | 抖动严重的素材即使分辨率高也不可用 |
| 清晰度 | `visual_stats.edge_density` + `texture_complexity` | 组合阈值 | 对焦不准的素材技术上是废片 |

### 3.2 画面美感 (aesthetic_score) — 权重 20%

**这是全新维度**，完全基于现有 `visual_stats` 字段构建，无需额外模型。

```python
def compute_aesthetic_score(visual_stats):
    scores = {}

    # --- 3.2.1 曝光评分 (exposure_score) ---
    brightness = visual_stats.get('brightness_mean', 0.5)
    brightness_std = visual_stats.get('brightness_std', 0.15)

    # 最佳曝光区间：0.30-0.70（中间调）
    if 0.35 <= brightness <= 0.65:
        exposure_base = 0.95
    elif 0.25 <= brightness <= 0.75:
        exposure_base = 0.80
    elif 0.15 <= brightness <= 0.85:
        exposure_base = 0.55
    else:
        exposure_base = 0.25  # 严重过曝或欠曝

    # 动态范围奖励：brightness_std 适中说明明暗层次丰富
    if 0.08 <= brightness_std <= 0.25:
        dynamic_bonus = 0.10
    elif brightness_std > 0.30:
        dynamic_bonus = -0.05  # 过于极端
    else:
        dynamic_bonus = 0.0

    scores['exposure'] = min(1.0, max(0.0, exposure_base + dynamic_bonus))

    # --- 3.2.2 色彩和谐度 (color_harmony_score) ---
    saturation = visual_stats.get('saturation_mean', 0.3)
    saturation_std = visual_stats.get('saturation_std', 0.1)
    color_temp = visual_stats.get('color_temp', 0.0)
    blue_ratio = visual_stats.get('blue_ratio', 0.33)
    green_ratio = visual_stats.get('green_ratio', 0.33)
    red_ratio = visual_stats.get('red_ratio', 0.33)

    # 饱和度：0.25-0.65 为宜（太淡无力，太艳刺眼）
    if 0.25 <= saturation <= 0.55:
        sat_score = 0.90
    elif 0.15 <= saturation <= 0.65:
        sat_score = 0.70
    elif saturation > 0.75:
        sat_score = 0.45  # 过饱和
    else:
        sat_score = 0.50  # 灰暗

    # 色彩统一性：std 低 = 和谐统一
    if saturation_std < 0.08:
        uniformity_bonus = 0.10
    elif saturation_std < 0.15:
        uniformity_bonus = 0.05
    else:
        uniformity_bonus = -0.05

    # 色调倾向性：有明确色调倾向比灰蒙蒙好
    color_max = max(blue_ratio, green_ratio, red_ratio)
    color_min = min(blue_ratio, green_ratio, red_ratio)
    color_range = color_max - color_min
    if color_range > 0.08:
        tonal_bonus = 0.05  # 有明确色调倾向
    else:
        tonal_bonus = 0.0

    scores['color_harmony'] = min(1.0, max(0.0, sat_score + uniformity_bonus + tonal_bonus))

    # --- 3.2.3 构图复杂度评分 (composition_score) ---
    edge_density = visual_stats.get('edge_density', 0.1)
    texture = visual_stats.get('texture_complexity', 0.1)
    face_ratio = visual_stats.get('face_ratio', 0.0)

    # 理想的构图：有内容但不杂乱
    # edge_density 0.05-0.20 = 适中（有主体有层次）
    if 0.06 <= edge_density <= 0.18:
        complexity = 0.90
    elif 0.04 <= edge_density <= 0.25:
        complexity = 0.70
    elif edge_density > 0.30:
        complexity = 0.40  # 画面杂乱
    else:
        complexity = 0.50  # 画面过于单调

    # 人脸构图奖励：有人脸通常构图更有意图
    if 0.15 <= face_ratio <= 0.60:
        face_bonus = 0.08
    elif face_ratio > 0.80:
        face_bonus = -0.03  # 怼脸拍，可能构图差
    else:
        face_bonus = 0.0

    scores['composition'] = min(1.0, max(0.0, complexity + face_bonus))

    # --- 3.2.4 运动美感 (motion_aesthetic) ---
    motion = visual_stats.get('motion_score', 0)

    # 空镜/风景最佳运动：缓慢推移（2-12）
    # 动作场景允许更高运动量
    if 2 <= motion <= 12:
        motion_beauty = 0.90   # 缓慢优雅运镜
    elif motion < 2:
        motion_beauty = 0.70   # 完全静止，可能呆板
    elif 12 < motion <= 20:
        motion_beauty = 0.65   # 中等运动
    elif 20 < motion <= 35:
        motion_beauty = 0.45   # 较快运动
    else:
        motion_beauty = 0.25   # 剧烈运动/抖动

    scores['motion_aesthetic'] = motion_beauty

    # --- 3.2.5 光影质量 (lighting_score) ---
    # 综合亮度 + 对比度（std）+ 色温一致性
    if brightness >= 0.30 and brightness <= 0.70 and brightness_std >= 0.10:
        lighting = 0.85  # 曝光好 + 有层次
    elif brightness >= 0.20 and brightness <= 0.80:
        lighting = 0.65
    else:
        lighting = 0.35

    # 偏暖 / 偏冷 都比完全中性更有情感表达
    if abs(color_temp) > 0.04:
        lighting += 0.08  # 有明确色温 = 有光影意图
    scores['lighting'] = min(1.0, max(0.0, lighting))

    # --- 汇总 ---
    aesthetic = (
        scores['exposure']        * 0.20
      + scores['color_harmony']   * 0.25
      + scores['composition']     * 0.25
      + scores['motion_aesthetic'] * 0.15
      + scores['lighting']        * 0.15
    )

    return {
        'aesthetic_score': round(aesthetic, 4),
        'sub_scores': {k: round(v, 4) for k, v in scores.items()},
        'aesthetic_tier': (
            'stunning' if aesthetic >= 0.85 else
            'beautiful' if aesthetic >= 0.70 else
            'decent' if aesthetic >= 0.50 else
            'mediocre' if aesthetic >= 0.35 else
            'poor'
        )
    }
```

**五个子维度对照表：**

| 子维度 | 衡量什么 | 理想值 | 差值 | 数据来源 |
|--------|---------|--------|------|---------|
| 曝光 (20%) | 是否过曝/欠曝 | brightness 0.35-0.65 | <0.15 或 >0.85 | brightness_mean, brightness_std |
| 色彩和谐度 (25%) | 色彩是否舒服 | saturation 0.25-0.55, std<0.08 | sat>0.75 或 <0.15 | saturation_mean/std, color ratios |
| 构图 (25%) | 画面是否有层次 | edge 0.06-0.18 | edge>0.30(杂乱) 或 <0.04(空洞) | edge_density, texture, face_ratio |
| 运动美感 (15%) | 运镜是否优雅 | motion 2-12 | >35(抖动) | motion_score |
| 光影 (15%) | 光影是否有表现力 | 适中亮度+有层次+有色温倾向 | 极暗/极亮+无层次 | brightness, std, color_temp |

### 3.3 音频质量 (audio_score) — 权重 12%

**直接复用 `audio_quality.py` 的 `quality_score`**，已经是加权后的 0-1 分数。

```python
def compute_audio_score(audio_info):
    if audio_info is None:
        return 0.5  # 无音轨素材给中间分（不惩罚空镜）

    base_score = audio_info.get('quality_score', 0.5)

    # 额外奖惩
    issues = audio_info.get('issues', [])
    penalty = len(issues) * 0.03  # 每个 issue 扣 3 分

    # 特殊情况：纯环境音（无人声但有自然音）
    # 对于空镜素材，环境音质量也很重要
    snr = audio_info.get('snr_db', 0)
    if snr >= 25:
        env_bonus = 0.05  # 干净的环境音
    else:
        env_bonus = 0.0

    return min(1.0, max(0.0, base_score - penalty + env_bonus))
```

### 3.4 叙事价值 (narrative_score) — 权重 18%

**评估这个素材在视频叙事中有多大用途。**

```python
def compute_narrative_score(asset_info, analysis_json, library_stats):
    scores = {}

    # --- 3.4.1 旁白/语音伴随度 (voiceover_coverage) ---
    # 有旁白 = 有人在讲述 = 素材与叙事绑定
    asr_text = analysis_json.get('asr_text', '')
    asr_word_count = len(asr_text.split()) if asr_text else 0
    duration = asset_info.get('duration', 0)

    if duration > 0 and asr_word_count > 0:
        # 每秒约2-3个词为正常语速
        words_per_sec = asr_word_count / duration
        if words_per_sec >= 1.5:
            scores['voiceover'] = 0.95    # 密集旁白，高叙事绑定
        elif words_per_sec >= 0.5:
            scores['voiceover'] = 0.75    # 有旁白
        else:
            scores['voiceover'] = 0.55    # 稀疏旁白
    else:
        scores['voiceover'] = 0.20        # 无语音（纯空镜）

    # --- 3.4.2 信息密度 (info_density) ---
    ocr_text = analysis_json.get('ocr_text', '')
    objects = analysis_json.get('objects', [])
    tags = analysis_json.get('tags', [])

    info_signals = 0
    if asr_word_count > 10: info_signals += 1
    if len(ocr_text) > 5: info_signals += 1
    if len(objects) >= 3: info_signals += 1
    if len(tags) >= 5: info_signals += 1

    scores['info_density'] = min(1.0, 0.30 + info_signals * 0.18)

    # --- 3.4.3 情感强度 (emotional_intensity) ---
    mood = analysis_json.get('semantic', {}).get('mood', '')
    emotion_intensity = analysis_json.get('semantic', {}).get('emotion_intensity', 0.5)

    # 强情感词汇检测
    strong_emotions = {'震撼', '感动', '恐惧', '兴奋', '悲伤', '愤怒', '惊喜',
                       'stunning', 'emotional', 'exciting', 'dramatic', 'intense'}
    has_strong_emotion = any(e in mood.lower() for e in strong_emotions)

    if has_strong_emotion or emotion_intensity >= 0.8:
        scores['emotion'] = 0.90
    elif emotion_intensity >= 0.6:
        scores['emotion'] = 0.70
    elif emotion_intensity >= 0.4:
        scores['emotion'] = 0.50
    else:
        scores['emotion'] = 0.30  # 平淡无感

    # --- 3.4.4 场景叙事角色 (narrative_role_value) ---
    narrative_role = analysis_json.get('semantic', {}).get('narrative_role', 'general_broll')
    role_values = {
        'hero_shot': 0.95,          # 高光镜头
        'establishing': 0.85,       # 建立镜头
        'interview': 0.80,          # 采访
        'atmospheric_broll': 0.65,  # 氛围空镜
        'transition': 0.60,         # 过渡
        'general_broll': 0.45,      # 一般 B-roll
        'filler': 0.25,             # 填充镜头
    }
    scores['role'] = role_values.get(narrative_role, 0.45)

    # --- 3.4.5 时长适用性 (duration_fitness) ---
    # 太短(<1s)难以使用，太长(>60s)需要裁剪
    if 3 <= duration <= 15:
        scores['duration_fit'] = 0.90    # 黄金时长
    elif 1.5 <= duration <= 30:
        scores['duration_fit'] = 0.75
    elif 0.5 <= duration <= 60:
        scores['duration_fit'] = 0.55
    elif duration < 0.5:
        scores['duration_fit'] = 0.15    # 残片
    else:
        scores['duration_fit'] = 0.45    # 过长

    # --- 汇总 ---
    narrative = (
        scores['voiceover']     * 0.30
      + scores['info_density']  * 0.20
      + scores['emotion']       * 0.20
      + scores['role']          * 0.15
      + scores['duration_fit']  * 0.15
    )

    return {
        'narrative_score': round(narrative, 4),
        'sub_scores': {k: round(v, 4) for k, v in scores.items()},
        'has_voiceover': asr_word_count > 0,
        'is_pure_broll': asr_word_count == 0 and len(ocr_text) < 5
    }
```

### 3.5 独特性 (uniqueness_score) — 权重 8%

```python
def compute_uniqueness_score(asset_info, library_stats):
    scores = {}

    # --- 3.5.1 视觉去重 (visual_uniqueness) ---
    phash = asset_info.get('phash', '')
    similar_count = library_stats.get('similar_assets_count', 0)  # Hamming ≤ 5 的数量

    if similar_count == 0:
        scores['visual_unique'] = 1.0     # 完全独特
    elif similar_count == 1:
        scores['visual_unique'] = 0.70    # 有 1 个相似
    elif similar_count <= 3:
        scores['visual_unique'] = 0.45    # 有几个相似
    else:
        scores['visual_unique'] = 0.20    # 大量重复

    # --- 3.5.2 场景稀缺度 (scene_rarity) ---
    scene_type = asset_info.get('scene_type', 'unknown')
    scene_count_in_library = library_stats.get('scene_type_counts', {}).get(scene_type, 0)
    total_assets = library_stats.get('total_assets', 1)

    scene_ratio = scene_count_in_library / max(total_assets, 1)
    if scene_ratio < 0.02:
        scores['scene_rarity'] = 0.95    # 极稀缺场景
    elif scene_ratio < 0.05:
        scores['scene_rarity'] = 0.80
    elif scene_ratio < 0.15:
        scores['scene_rarity'] = 0.60
    elif scene_ratio < 0.30:
        scores['scene_rarity'] = 0.40
    else:
        scores['scene_rarity'] = 0.25    # 大量同类

    # --- 3.5.3 时间独特性 (temporal_rarity) ---
    time_of_day = asset_info.get('time_of_day', 'unknown')
    rare_times = {'golden_hour', 'blue_hour', 'dawn', 'dusk', 'night', 'sunrise', 'sunset'}
    if time_of_day in rare_times:
        scores['temporal_rare'] = 0.85
    else:
        scores['temporal_rare'] = 0.45

    uniqueness = (
        scores['visual_unique']  * 0.50
      + scores['scene_rarity']   * 0.30
      + scores['temporal_rare']  * 0.20
    )

    return {
        'uniqueness_score': round(uniqueness, 4),
        'sub_scores': {k: round(v, 4) for k, v in scores.items()},
        'is_duplicate': similar_count >= 3
    }
```

### 3.6 编辑适用性 (edit_fitness_score) — 权重 15%

**新维度：这个素材在实际剪辑中好不好用？**

```python
def compute_edit_fitness(asset_info, visual_stats, audio_info):
    scores = {}

    # --- 3.6.1 入点/出点干净度 (cut_cleanness) ---
    # 基于首尾帧的运动量估算
    motion = visual_stats.get('motion_score', 0)
    duration = asset_info.get('duration', 0)

    # 运动量低的素材更容易找到干净的剪辑点
    if motion < 8:
        scores['cut_clean'] = 0.90
    elif motion < 15:
        scores['cut_clean'] = 0.70
    elif motion < 25:
        scores['cut_clean'] = 0.50
    else:
        scores['cut_clean'] = 0.30

    # --- 3.6.2 速度适应性 (speed_adaptability) ---
    # 可否变速使用（慢动作/快进）
    fps = asset_info.get('fps', 30)
    if fps >= 60:
        scores['speed_adapt'] = 0.95    # 高帧率，慢动作素材
    elif fps >= 30:
        scores['speed_adapt'] = 0.75    # 标准帧率
    elif fps >= 24:
        scores['speed_adapt'] = 0.60    # 电影帧率
    else:
        scores['speed_adapt'] = 0.35    # 低帧率，变速受限

    # --- 3.6.3 裁剪灵活度 (crop_flexibility) ---
    width = asset_info.get('width', 1920)
    height = asset_info.get('height', 1080)
    resolution_area = width * height

    # 高分辨率 = 可裁剪空间大 = 更灵活
    if resolution_area >= 3840 * 2160:
        scores['crop_flex'] = 0.95      # 4K 可裁成任意比例
    elif resolution_area >= 1920 * 1080:
        scores['crop_flex'] = 0.75      # 1080p 有一定裁剪空间
    elif resolution_area >= 1280 * 720:
        scores['crop_flex'] = 0.50
    else:
        scores['crop_flex'] = 0.25      # 低分辨率无法裁剪

    # --- 3.6.4 音画同步度 (av_sync_potential) ---
    has_audio = audio_info is not None
    audio_quality = audio_info.get('quality_score', 0) if audio_info else 0

    if has_audio and audio_quality >= 0.7:
        scores['av_sync'] = 0.90        # 有高质量音频
    elif has_audio and audio_quality >= 0.4:
        scores['av_sync'] = 0.65        # 有可用音频
    elif has_audio:
        scores['av_sync'] = 0.40        # 有音频但质量差
    else:
        scores['av_sync'] = 0.50        # 无音频（空镜正常）

    # --- 3.6.5 色彩后期空间 (color_grade_potential) ---
    brightness = visual_stats.get('brightness_mean', 0.5)
    brightness_std = visual_stats.get('brightness_std', 0.15)
    saturation = visual_stats.get('saturation_mean', 0.3)

    # 中间调 + 适中饱和 = 调色空间大
    if 0.30 <= brightness <= 0.70 and 0.20 <= saturation <= 0.55:
        scores['color_potential'] = 0.90  # 后期空间充裕
    elif 0.20 <= brightness <= 0.80:
        scores['color_potential'] = 0.65
    else:
        scores['color_potential'] = 0.35  # 过曝/欠曝，调色受限

    edit_fitness = (
        scores['cut_clean']       * 0.25
      + scores['speed_adapt']     * 0.15
      + scores['crop_flex']       * 0.20
      + scores['av_sync']         * 0.20
      + scores['color_potential'] * 0.20
    )

    return {
        'edit_fitness_score': round(edit_fitness, 4),
        'sub_scores': {k: round(v, 4) for k, v in scores.items()}
    }
```

### 3.7 内容丰富度 (content_richness) — 权重 12%

**衡量这个素材携带了多少可利用的信息。**

```python
def compute_content_richness(analysis_json, tag_results):
    scores = {}

    # --- 3.7.1 标签丰富度 (tag_richness) ---
    high_conf_tags = [t for t in tag_results if t['score'] >= 0.55]  # display threshold
    tag_count = len(high_conf_tags)

    if tag_count >= 15:
        scores['tag_rich'] = 0.95
    elif tag_count >= 10:
        scores['tag_rich'] = 0.80
    elif tag_count >= 5:
        scores['tag_rich'] = 0.60
    elif tag_count >= 2:
        scores['tag_rich'] = 0.40
    else:
        scores['tag_rich'] = 0.20

    # --- 3.7.2 语义维度覆盖 (semantic_coverage) ---
    semantic = analysis_json.get('semantic', {})
    filled_fields = sum(1 for v in semantic.values() if v and v != 'unknown')
    total_fields = 62  # 总共 62 个语义维度

    coverage_ratio = filled_fields / total_fields
    scores['semantic_cover'] = min(1.0, coverage_ratio * 1.5)  # 40%覆盖=0.6

    # --- 3.7.3 多模态信息源覆盖 (multimodal_coverage) ---
    sources_present = set()
    asr = analysis_json.get('asr_text', '')
    ocr = analysis_json.get('ocr_text', '')
    objects = analysis_json.get('objects', [])
    gps = analysis_json.get('gps', None)

    if asr: sources_present.add('asr')
    if ocr: sources_present.add('ocr')
    if objects: sources_present.add('vision')
    if gps: sources_present.add('gps')

    multimodal_count = len(sources_present)
    scores['multimodal'] = min(1.0, 0.25 + multimodal_count * 0.20)

    # --- 3.7.4 可检索性 (searchability) ---
    # 这个素材能被多少种搜索方式找到？
    has_text = bool(asr or ocr)
    has_tags = tag_count >= 3
    has_embedding = analysis_json.get('has_clip_embedding', False)
    has_description = bool(analysis_json.get('scene_description', ''))

    search_channels = sum([has_text, has_tags, has_embedding, has_description])
    scores['searchability'] = min(1.0, 0.20 + search_channels * 0.22)

    richness = (
        scores['tag_rich']       * 0.30
      + scores['semantic_cover'] * 0.25
      + scores['multimodal']     * 0.25
      + scores['searchability']  * 0.20
    )

    return {
        'content_richness': round(richness, 4),
        'sub_scores': {k: round(v, 4) for k, v in scores.items()}
    }
```

### 5.2 判定流程

```python
def evaluate_trash_status(score_bundle):
    """
    返回:
    {
        'is_trash': bool,
        'trash_level': 'none' | 'warn' | 'suggest_delete' | 'strong_suggest_delete',
        'triggered_rules': [...],
        'primary_reason': str,
        'can_be_saved_by': [str]  # 可能的补救方式
    }
    """
    triggered = []
    for rule in TRASH_RULES:
        if rule['condition'](score_bundle):
            triggered.append(rule)

    if not triggered:
        return {'is_trash': False, 'trash_level': 'none', 'triggered_rules': []}

    max_severity = max(t['severity'] for t in triggered)
    auto_deletes = [t for t in triggered if t['auto_suggest_delete']]

    # 救赎机制：某些高分维度可以挽救素材
    saveable_by = []
    if score_bundle.get('uniqueness_score', 0) >= 0.85:
        saveable_by.append('极高独特性（稀缺场景）')
    if score_bundle.get('narrative_score', 0) >= 0.80:
        saveable_by.append('高叙事价值（有重要旁白）')
    if score_bundle.get('aesthetic_score', 0) >= 0.85:
        saveable_by.append('极高美感（画面精美）')

    # 如果有高分维度可以挽救，降级处理
    if saveable_by and max_severity != 'critical':
        trash_level = 'warn'
    elif auto_deletes and max_severity == 'critical':
        trash_level = 'strong_suggest_delete'
    elif auto_deletes:
        trash_level = 'suggest_delete'
    else:
        trash_level = 'warn'

    return {
        'is_trash': True,
        'trash_level': trash_level,
        'triggered_rules': [t['id'] for t in triggered],
        'primary_reason': triggered[0]['reason_zh'],
        'all_reasons': [t['reason_zh'] for t in triggered],
        'can_be_saved_by': saveable_by,
    }
```
