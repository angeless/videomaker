## 2. 本轮实施计划

### 步骤 1: 在 security.py 中添加安全事件审计

在 `_guard_local_api_token()` 的 3 个拦截点分别添加 audit() 调用：
- Origin 校验失败 → `audit("security_origin_fail", "security", ...)`
- CSRF 校验失败 → `audit("security_csrf_fail", "security", ...)`
- API Token 校验失败 → `audit("security_token_fail", "security", ...)`

### 步骤 2: 添加暴力破解检测

在 security.py 中添加内存计数器：
- `_auth_fail_counter`: `Dict[str, List[float]]`，key=IP，value=失败时间戳列表
- 每次 token 校验失败时记录时间戳
- 1 分钟内同 IP 达到 5 次时触发 `audit("security_brute_force", ...)`
- 定期清理过期条目（>60s）

### 步骤 3: 排查剩余路由输入校验

排查 `system_routes.py`、`timeline_routes.py` 中的 `payload.get()` 使用，补全 `parse_str_param`/`parse_int_param` 校验。

### 步骤 4: 补充测试

新增 `tests/test_security_audit.py`，覆盖 AC-01~AC-03。
