# 视频制作助手 - 用户体验研究报告

> 测试日期：2026-03-15
> 测试人员：UX Researcher (模拟角色：旅行 Vlogger，拥有 164 条加拿大旅行素材)
> 测试环境：macOS, Chrome, Vue Dev Server (5173) + Flask Backend (9527)
> 测试范围：素材库、创作流程、自定义工作流、工具箱、设置 — 全链路端到端

---

## 一、Executive Summary

### 产品定位判断

本产品定位为 **AI 驱动的视频内容运营一站式工具**，面向具备一定技术理解力的内容创作者（独立 Vlogger / 小团队运营）。它试图解决一个真实痛点：**从大量原始素材到可发布内容之间的漫长流程**。

### 核心结论

| 维度 | 评分 (5分制) | 一句话 |
|------|:-----------:|--------|
| 功能完整度 | 3.5 | 全链路骨架完整，但多数功能依赖后端 API 未贯通 |
| 信息架构 | 3.0 | 三层导航（顶栏/侧栏/页内Tab）存在概念重叠 |
| 交互易用性 | 2.5 | 大量代码级标识符暴露给用户，表单缺乏引导 |
| 视觉一致性 | 3.5 | 暗色主题统一，但中英文混杂破坏专业感 |
| 错误处理 | 2.0 | API 失败时仅显示 "HTTP 500"，无恢复建议 |
| 可用性阻滞 | 2.0 | Vite→Backend 代理未贯通，核心流程跑不通 |
| 安全性 | 3.5 | API Key 已脱敏，但 titlebar 暴露完整本地路径 |

**总分：2.9 / 5 — 产品处于"可演示但不可日常使用"阶段。**

## 二、用户旅程分析 (User Journey)

### 场景设定

> 我是一个旅行 Vlogger，刚从加拿大回来，iPhone 里有 164 条素材（短视频/Live Photo/长镜头混合）。
> 我想用这个工具完成：整理素材 → 构思选题 → 生成脚本 → 剪辑 → 加字幕和配乐 → 导出发小红书/YouTube。

---

### 旅程 1：打开软件 — 首次印象

**实际体验**：
- 打开后直接进入"创作"页面，显示上次项目的"精渲染-渲染完成"状态
- 没有任何欢迎引导或项目选择入口
- 左下角有"新建项目"和"打开项目"按钮，但视觉权重极低

**问题**：
| # | 严重度 | 问题 | 影响 |
|---|--------|------|------|
| 1.1 | P1 | **无新手引导流程 (Onboarding)** | 新用户完全不知道从哪里开始。164 条素材该怎么导入？7步工作流是什么？没有任何说明 |
| 1.2 | P2 | **项目名不可读** `proj_selected_20260312_193013` | 用户无法识别"这是哪个项目"。应支持自定义项目名 |
| 1.3 | P2 | **Titlebar 暴露完整本地路径** `/Users/angelwang/videoeditor/...` | 安全隐患（录屏/截图时泄露），且对用户无用 |
| 1.4 | P3 | **最近项目列表被截断** 显示 `proj_selected_20...` | 唯一的项目名已经不可读，截断后更不可读 |

**建议**：
- 首次打开 → 显示 Welcome 页，含"导入素材开始新项目"大按钮
- 项目名改为可编辑字段，默认用日期+主题（如"加拿大旅行 2026.03"）
- Titlebar 只显示项目名，不显示本地路径

---

### 旅程 2：整理素材 — 素材库

**实际体验**：
- 素材库展示 164 条视频，支持网格/列表切换
- 搜索"加拿大 风景"→ 命中 113 条，搜索速度快
- 部分素材有缩略图，部分显示灰色胶片占位图标
- 标签系统已建立（人物/天空/水面/风景等），但中英文混杂
- "导入素材"面板默认展开，占据大量首屏空间

**问题**：
| # | 严重度 | 问题 | 影响 |
|---|--------|------|------|
| 2.1 | P1 | **标签中英文混杂** 同一卡片上出现 "人物" + "activity" + "intimate, personal" | 严重破坏专业感。vlogger 看到 "intimate, personal" 会困惑 |
| 2.2 | P1 | **大量素材缩略图缺失** 搜索结果中约 40% 显示灰色占位符 | 素材库的核心价值是"看图选素材"，没有缩略图等于瞎选 |
| 2.3 | P2 | **"+175 更多"标签无法展开** 点击后无反应 | 用户想看完整标签列表但做不到 |
| 2.4 | P2 | **导入面板默认展开** 首次进入占据 50% 首屏 | 对已有素材的用户是干扰。应默认收起，或在空库时才默认展开 |
| 2.5 | P2 | **质量分数 "Q0.85" / "Q0.95" 缺乏解释** | 用户不知道 Q 是什么、0.85 意味着什么 |
| 2.6 | P3 | **搜索后导入面板自动折叠** 出现 "面板已折叠以展示搜索结果" | 可以理解但没有 transition 动画，感觉突兀 |
| 2.7 | P3 | **搜索类型下拉 "智能搜索" / "全部"** 含义不清 | 智能搜索 vs 全部搜索区别是什么？没有 tooltip 说明 |

**亮点**：
- 网格/列表双视图切换体验流畅
- 列表视图信息密度合理（文件名/类型/时长/分辨率/标签/质量）
- 视频时长标签（2s / 14s / 1:52）显示在缩略图右下角，直观
- GPS 坐标（如 29.6605, 91.1224）能显示在卡片上，有旅行场景价值

### 旅程 3：构思选题 — 创作 > 选题构思

**实际体验**：
- 选题库有 5 条预置模板（如"雪国荒野·一个人的加拿大冬日"）
- 选题文案区域有"选题 Slug"和"目标时长(秒)"两个输入框
- "生成文案草案"按钮 — 提示"请先输入选题 Slug"

**问题**：
| # | 严重度 | 问题 | 影响 |
|---|--------|------|------|
| 3.1 | P1 | **"选题 Slug" 概念对用户不可理解** | Slug 是开发术语。Vlogger 不知道 slug 是什么，也不知道该填什么 |
| 3.2 | P2 | **分类 placeholder "如 travel"** 用英文 | 全中文界面里突然出现英文 placeholder，不一致 |
| 3.3 | P2 | **选题模板不可点击选用** | 看到"雪国荒野"模板后，没有"使用此模板"按钮，无法直接填充到下方表单 |
| 3.4 | P3 | **"从素材生成"按钮无响应反馈** | 点击后什么也没发生（因 API 500），但没有 loading 态或错误提示 |

**建议**：
- "选题 Slug" → 改为"选题关键词"或"选题标题"
- 模板列表每条加"使用"按钮，点击后自动填充表单
- "从素材生成"应基于已导入素材的标签自动推荐选题

### 旅程 4：剪辑编排 — 创作 > 剪辑编排

**实际体验**：
- 两个功能区：文字粗剪 + 短视频快剪
- 文字粗剪：需先"加载字幕"，支持去除口头词（嗯/啊/然后/就是）、保留/丢弃指定句号
- 短视频快剪：目标时长 30s，最大片段数 8

**问题**：
| # | 严重度 | 问题 | 影响 |
|---|--------|------|------|
| 4.1 | P1 | **"保留句号"/"丢弃句号"概念不清** placeholder "如 1-5,8,10-12" | 什么是"句号"？是字幕的第几句？没有上下文，用户无法操作 |
| 4.2 | P2 | **"合并间隔(秒) 0.15" 无解释** | 0.15 秒的间隔是什么意思？对非技术用户完全不可理解 |
| 4.3 | P2 | **两个功能区没有视觉分隔** | 文字粗剪和短视频快剪紧挨在一起，用一个更清晰的分隔线或卡片包裹 |

**建议**：
- "保留句号"→"保留句子"，并在加载字幕后直接显示句子列表，让用户勾选
- 提供字幕时间轴可视化预览

| 5.3 | P3 | **"编辑器: 内置 FFmpeg"** 对用户不友好 | 用户不需要知道 FFmpeg 是什么 |

## 三、架构级问题

### 3.1 前后端代理未贯通 (P0 - BLOCKER)

**现象**：所有 `/api/*` 请求发往 `localhost:5173`（Vite 前端）而非 `localhost:9527`（Flask 后端），导致全站 500 错误。

**影响**：
- 工作流模板无法加载
- 设置页无法读取/保存配置
- 所有"生成"类操作均不可用
- 整个产品变成静态页面展示

**根因推测**：Vite 的 `proxy` 配置未正确指向后端端口，或后端服务未在预期端口启动。

**建议**：在 `vite.config.js` 中确认 proxy 配置：
```js
server: {
  proxy: {
    '/api': { target: 'http://localhost:9527', changeOrigin: true }
  }
}
```

### 3.2 信息架构重叠

```
当前结构：
  顶栏导航：素材库 | 创作 | 工作流 | 工具箱 | 设置
  创作侧栏：7步工作流 | 选题构思 | 剪辑编排 | 画面优化 | 音频设计 | 字幕制作 | 发布导出 | 工作流画布
  工具箱侧栏：选题库 | 选题文案 | 文字粗剪 | 短视频快剪 | 视频精剪 | 配乐配音 | 字幕校准 | ...

问题：创作侧栏和工具箱侧栏有 80% 的功能重叠
```

**建议重构**：
```
顶栏导航：首页 | 素材库 | 创作 | 工具 | 设置
创作 = 项目级流程（7步工作流 或 自由画布）
工具 = 独立单项能力（不依赖项目上下文）
合并"工作流"到"创作"侧栏中
```

### 3.3 国际化不完整

中英文混杂贯穿整个产品：
- 标签："人物" + "activity" + "intimate, personal" + "general"
- 表单值："travel_story" / "elevenlabs" / "short_video"
- UI 文案："Slug" / "Dry-run" / "Voice ID" / "Embedding 模型"
- Placeholder："如 travel" / "youtube,douyin,xiaohongshu"

应统一为中文界面 + 中文标签 + 中文 placeholder。技术标识符仅在开发者模式下显示。

## 四、安全性评估

| 项目 | 状态 | 说明 |
|------|------|------|

## 五、响应式设计评估

| 设备 | 表现 | 说明 |
|------|------|------|
| Desktop (1280+) | 良好 | 三栏布局合理，信息密度适当 |

## 六、可用性亮点 (做得好的地方)

1. **7 步工作流进度条** — 顶部的绿色圆点 + 步骤名称链式展示，清晰直观
2. **渲染成品预览** — 完成渲染后直接内嵌视频播放器 + "下载成品" + "在 Finder 中查看"，闭环完整
3. **素材库双视图** — 网格视图看缩略图，列表视图看元数据，切换丝滑
4. **API Key 安全处理** — 脱敏显示 + 配置状态标签，专业
5. **工作流画布** — 点状网格背景 + 节点系统 + 保存/运行/清空工具栏，基础框架完整
6. **NLE 连接器检测** — 自动检测本地安装的剪辑软件，想法正确
7. **素材 GPS 信息展示** — 在卡片上显示拍摄坐标，对旅行 vlogger 有价值
8. **错误降级提示** — "未检测到外部编辑器，仍可使用内置 FFmpeg 精剪"，优雅降级

## 七、Bug 汇总 (按优先级)

### P0 — 阻塞性 (无法完成核心任务)
| ID | 问题 | 位置 |
|----|------|------|

## 十一、最终建议：面向真实 Vlogger 的 3 个关键改进

### 1. "说人话" — 消灭全部代码标识符
把 `travel_story` → "旅行叙事"，`image_semantic` → "图片语义分析"，`Slug` → "选题标题"。
这一项改动就能让产品从"工程师工具"变成"创作者工具"。

### 2. "一键启动" — 统一开发/运行入口
提供 `python launcher.py` 一条命令同时启动前端+后端，或把 Flask 嵌入 Electron/pywebview。
当前需要用户分别启动两个服务器的体验对非技术用户是不可接受的。

### 3. "看得见进度" — 步骤可回溯 + 步骤状态持久化
7 步工作流的进度条应该可以点击跳回任意已完成步骤查看/修改产物（选题/脚本/粗剪），
而非只能看到最终步骤。这是"编辑"和"仅渲染"的本质区别。
