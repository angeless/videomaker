## 4. 实现约束

1. **只做 extract，不做重构** — 函数签名、行为、返回值完全不变
2. **不改 Blueprint 注册方式** — 保持 lambda 闭包依赖注入
3. **不引入新的抽象层或框架** — 纯 Python 模块提取
4. **server.py 中保留 import + 赋值别名** — 确保现有调用方（routes 中的 lambda 闭包）不受影响
5. **每批次后全量回归** — 201+ tests 全部通过
6. **不合并或拆分已有 routes 文件**
7. **不改变对外 API 签名**

### 提取模式

```python
# server.py 中原有：
def _some_function(arg):
    ...

# 提取后 server.py 改为：
from modules.app_api.services.new_module import _some_function  # noqa: F401
# 或保留局部别名：
from modules.app_api.services.new_module import _some_function as _some_function
```

这样所有通过 lambda 闭包引用 `_some_function` 的 Blueprint 注册代码无需任何修改。
