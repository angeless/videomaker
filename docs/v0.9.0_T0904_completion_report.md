## 实现说明

### 步骤 1: security.py 安全事件审计

在 `_guard_local_api_token()` 的 3 个拦截点添加 `_audit_security_event()` 调用：

| 拦截点 | operation | 触发条件 |
|--------|-----------|----------|
| Origin 校验 | `security_origin_fail` | 非本地 Origin 发起的 mutating 请求 |
| CSRF 校验 | `security_csrf_fail` | CSRF token 缺失或不匹配 |
| API Token 校验 | `security_token_fail` | API Token 缺失或不匹配 |

所有 audit 调用使用 `try/except` 包裹，遵循 best-effort 原则，不阻塞请求处理。

### 步骤 2: 暴力破解检测

新增 `_record_auth_failure(ip)` 函数：
- 使用 `_auth_fail_counter: Dict[str, List[float]]` 记录每 IP 的失败时间戳
- 每次记录时自动清理 >60s 的过期条目
- 同一 IP 在 60s 内达到 5 次失败时触发 `security_brute_force` 审计事件
- 触发后重置计数器，避免重复告警
- **仅检测 + 记录，不阻断请求**（按约束要求）
