# 中文视频/图片语义关键词库设计方案（参考版）

这份方案不是单纯给你一个“大词表”，而是给你一个更适合做视频/图片识别的 **层级语义库**。  
如果只把关键词越堆越多，识别效果通常不会明显变好；真正有用的是：

1. 把词分层：地点 / 场景 / 物品 / 人物 / 动作 / 时间天气 / 风格镜头 / 抽象主题。
2. 给每个词补充别名、同义词、上位词、下位词。
3. 支持多标签并行输出，而不是只输出一个主标签。
4. 支持“用户自定义关键词”与“自动扩展候选词”。

## 设计原则

- 不要只做平面关键词列表，必须做“层级标签 + 同义词 + 复合规则”。
- 同一画面尽量输出多标签，而不是只给一个主标签。
- 地点、人物、动作、物品、天气、时间、镜头风格应分通道评分，最后再融合。
- 把“厨房”“下厨”“锅”“母亲做饭”区分成 place / scene / object / action / person 五种类型。
- 所有用户自定义词都应带父类，避免孤立新词越加越乱。
- 不要把自动学习得到的新词直接写死到主库，应先进入待审核池。
- 支持别名映射，例如“电瓶车→电动车”“小卖部→便利店/小商店”。
- 支持负向词，例如识别“医生”时要排除“角色扮演”“万圣节装扮”。
- 对视频建议做关键帧 + 时间窗口聚合，而不是逐帧硬判。
- 同一视频中可分镜头存标签，再生成全片级摘要标签。

## 建议的词库结构

每个关键词建议至少包含这些字段：

- `keyword`: 主关键词
- `aliases`: 别名/口语/同义表达
- `top_category`: 顶层分类
- `subcategory`: 子分类
- `parent_keywords`: 上位词
- `related_keywords`: 相关词
- `negative_keywords`: 负向排除词
- `confidence_threshold`: 置信阈值
- `is_user_defined`: 是否用户自定义
- `allow_auto_expand`: 是否允许自动扩展

## 自动学习与扩展机制

1. 从视频帧、图片、OCR、字幕、ASR、现有标签中抽取候选词。
2. 统一做归一化：全半角、繁简、大小写、停用词、数字格式、品牌/型号切分。
3. 把候选词映射到层级库，优先命中精确词，再命中别名、同义词、上位词。
4. 对未命中的高频新词做向量聚类，聚合同一语义的不同表达。
5. 结合共现规则判断候选词是否可信，例如“锅+灶台+冰箱”可提升“厨房”置信度。
6. 为每个候选词计算支持度、精确率、用户确认率、跨视频复现率。
7. 达到阈值后进入“待审核新词池”，默认不直接写入公库，只写入项目词库或用户词库。
8. 用户确认后升级为正式关键词或正式别名，并记录来源与版本。
9. 当多个用户独立添加同一新词或同义表达时，可以自动提升为全局别名。
10. 定期做反向清洗：删除长期低置信、低复现、易混淆的词条。

## 复合标签模板（不要穷举所有组合，用规则组合）

- **基础描述模板**：时间段 + 天气 + 地点 + 人物 + 动作 + 物品。例：傍晚 + 雨天 + 城市街道 + 年轻女性 + 行走 + 雨伞
- **场景归纳模板**：地点 + 场景 + 人物 + 关键物品。例：厨房 + 做饭 + 母亲 + 锅 / 刀 / 砧板
- **旅行视频模板**：地点 + 时间段 + 天气 + 人物 + 行为 + 镜头。例：海边 + 日落 + 晴天 + 游客 + 打卡拍照 + 航拍
- **职业识别模板**：人物职业 + 服装 + 动作 + 专属物品 + 地点。例：医生 + 白大褂 + 问诊 + 听诊器 + 诊室
- **体育模板**：运动场地 + 人物 + 动作 + 器材 + 比赛状态。例：篮球场 + 运动员 + 投篮 + 篮球 + 比赛
- **电商展示模板**：产品 + 人物 + 动作 + 风格 + 文本媒体。例：护肤品 + 主播 + 讲解 + 商业广告风 + 字幕
- **安全事件模板**：风险主题 + 地点 + 动作 + 应急物品 + 人物。例：火灾风险 + 工厂车间 + 灭火 + 灭火器 + 消防员
- **亲子模板**：家庭角色 + 儿童状态 + 动作 + 玩具 + 地点。例：母亲 + 儿童 + 陪伴 + 积木 + 客厅
- **宠物模板**：动物 + 动作 + 道具 + 地点 + 氛围。例：狗 + 奔跑 + 牵引绳 + 公园 + 欢乐
- **镜头语言模板**：主体 + 景别 + 镜头运动 + 光照 + 氛围。例：歌手 + 特写 + 推镜 + 舞台灯光 + 紧张

## 负向规则示例

- 命中 听诊器, 白大褂 时建议提升 **医生**；排除：角色扮演, 万圣节装扮。
- 命中 锅, 灶台, 冰箱 时建议提升 **厨房**；排除：无。

## 落地建议

- 视频按镜头或时间窗口聚合标签，不要逐帧硬输出。
- 识别结果建议分为：
  - `主体标签`：人物、动物、物品、地点
  - `行为标签`：动作、事件、场景
  - `环境标签`：季节、天气、时间、光照
  - `画面标签`：镜头、风格、构图、清晰度
  - `抽象标签`：情绪、氛围、社会主题
- 输出时建议保留：
  - `原始命中词`
  - `归一化词`
  - `父级分类`
  - `置信度`
  - `触发依据`
- 用户自定义关键词最好独立存表，不要直接污染官方主词库。
- 每次模型学习后，保留版本号，支持回滚。
