## 一、现状分析

### 1.1 当前关键词体系

| 维度 | 现状 |
|------|------|
| 种子词条数 | ~2,124 条（25 大类） |
| 语义维度字段 | 62 个 |

| **垃圾素材识别** | ❌ 缺失 | 无"建议删除"标记机制 |

## 二、关键词扩展方案：从 2K → 10K+

### 2.1 扩展策略总览

```
目标：10,000+ 可检索语义关键词
路径：种子扩展 + 领域深挖 + 动态生成 + 用户沉淀
```

### 2.2 策略一：领域纵深扩展（+3,000 词）

当前 25 个大类中，每个大类平均只有 10-15 个种子词，远远不够。建议每个大类扩展到 50-100 个词。

**具体扩展方向：**

| 大类 | 现有词数 | 目标词数 | 扩展方向 |
|------|---------|---------|---------|
| objects 物体 | 15 | 80+ | 增加：日常用品(50+)、科技产品(20+)、装饰品(15+) |
| actions 动作 | 15 | 80+ | 增加：运动动作(20+)、工作场景(15+)、社交互动(15+)、创作行为(10+) |
| scenes 场景 | 15 | 100+ | 增加：商业空间(20+)、自然细分(30+)、居住空间(15+)、交通场景(10+) |
| mood 情绪 | 15 | 60+ | 增加：微妙情绪(20+)、氛围描述(15+)、叙事情感(10+) |
| food_cuisine 美食 | 15 | 80+ | 增加：菜系细分(30+)、烹饪方式(15+)、食材(20+) |
| nature_landscape | 12 | 80+ | 增加：地形(20+)、水体(15+)、植被(15+)、天象(10+) |
| style 风格 | 14 | 50+ | 增加：影像流派(15+)、调色风格(10+)、叙事风格(10+) |
| cultural_elements | 12 | 60+ | 增加：节日(20+)、民俗(15+)、宗教元素(10+) |

### 2.3 策略二：组合关键词生成（+2,000 词）

利用现有语义维度的笛卡尔积，自动生成有意义的组合关键词：

**规则示例：**
- `{场景} + {时间}` → "海边日落"、"城市夜景"、"山间清晨"
- `{情绪} + {场景}` → "治愈森林"、"孤独街头"、"热闹集市"
- `{动作} + {场景}` → "海边奔跑"、"咖啡馆阅读"、"公园散步"
- `{天气} + {场景}` → "雨中街道"、"雪地森林"、"雾中山路"
- `{拍摄手法} + {场景}` → "航拍城市"、"延时日出"、"跟拍骑行"

**实现方式：**
在 `_seed_concept_library` 之后增加一个 `_generate_composite_keywords()` 方法，按预定义模板交叉生成，并过滤掉语义不通的组合。

### 2.4 策略三：同义词/近义词网络扩展（+2,000 词）

当前别名系统只有 84 组，需要大幅扩展：

**方案 A：引入 WordNet / 大词林 / 同义词词林**
- 中文：使用《同义词词林》或 HIT-CIR 同义词林扩展版
- 英文：使用 WordNet synsets
- 每个种子词扩展 3-5 个近义词

**方案 B：LLM 批量扩展**
- 将每个种子词交给 LLM，让它生成 5-10 个相关搜索词
- 例如输入 "航拍" → 输出 "俯拍、鸟瞰、无人机视角、高空视角、上帝视角、俯视拍摄"
- 可以离线批量运行，结果人工审核后入库

**方案 C：用户搜索日志反哺**
- 记录用户实际搜索词
- 将高频但命中率低的搜索词加入关键词库
- 建立 "搜索词 → 标签" 的映射关系

### 2.5 策略四：行业/垂直领域词库（+2,000 词）

针对短视频常见垂类，构建专用词库：

| 垂类 | 词库规模 | 示例 |
|------|---------|------|
| 旅行Vlog | 300+ | 目的地名称、旅行方式、住宿类型、交通工具、旅行活动 |
| 美食探店 | 300+ | 菜品、口味、烹饪、餐厅类型、食材、摆盘 |
| 科技数码 | 200+ | 产品品类、品牌、功能、使用场景、评测维度 |
| 生活方式 | 200+ | 家居、收纳、穿搭、护肤、健身、日常 |
| 知识教育 | 200+ | 学科、方法论、图表、演示、案例 |
| 宠物 | 150+ | 品种、行为、互动、护理、用品 |
| 运动健身 | 200+ | 运动类型、动作、装备、场地、体能指标 |
| 城市风光 | 200+ | 建筑类型、天际线、街道、灯光、交通 |
| 自然风光 | 200+ | 地貌、水域、植物、动物、天象、季节细节 |

### 2.6 扩展后的词库规模预估

| 层级 | 词条数 | 来源 |

## 三、素材质量判断机制设计

### 3.1 设计目标

为每个素材（尤其是空镜/风景素材）生成一个**综合可用性评分**，并对低质量素材给出**建议删除/不推荐使用**的标记。

### 3.2 评分体系：五维评估模型

```
综合可用性评分 =
    技术质量(25%) + 美感评分(30%) + 叙事价值(20%) + 音频质量(15%) + 独特性(10%)
```

#### 维度一：技术质量（25%）— 已有基础

| 指标 | 计算方式 | 权重 |
|------|---------|------|
| 分辨率评分 | 4K(0.95) → 1080p(0.85) → 720p(0.70) → 480p(0.50) | 40% |
| 码率评分 | >10Mbps(0.95) → >5Mbps(0.85) → >2Mbps(0.70) | 30% |
| 稳定性 | 帧间运动方差（低=稳定） | 15% |
| 对焦清晰度 | 拉普拉斯方差（高=清晰） | 15% |

#### 维度二：美感评分（30%）— 需新增

这是当前体系中最缺失的部分。

| 指标 | 计算方式 | 说明 |
|------|---------|------|
| 构图评分 | 三分法/对称性/引导线检测 | 检测画面主体是否在三分点、是否有明显构图意图 |
| 色彩和谐度 | 色相分布 + 互补/类比色占比 | 参考 Adobe Color Wheel 理论 |
| 明暗对比 | 直方图分布均匀度 | 过曝/欠曝扣分，动态范围丰富加分 |
| 景深层次 | 前景/中景/背景清晰度差异 | 有明显景深虚化=专业感 |
| 视觉吸引力 | 基于 NIMA 或 AVA 模型的美学评分 | 可使用预训练美学评估模型 |

**推荐实现方案：**

1. **轻量方案（无额外模型）：** 基于现有视觉分析数据（亮度、饱和度、边缘密度、色温）的规则打分
2. **中量方案：** 引入 NIMA (Neural Image Assessment) 预训练模型，直接输出美学评分
3. **重量方案：** 微调美学模型 on 短视频/Vlog 数据集

**建议先用轻量方案快速上线，后续引入 NIMA。**

轻量方案的规则逻辑示例：

```python
def aesthetic_score_lite(visual_stats):
    score = 0.5  # 基准分

    # 色彩饱和度：适中最好（0.3-0.7）
    sat = visual_stats['saturation_mean']
    if 0.3 <= sat <= 0.7:
        score += 0.15
    elif sat < 0.15 or sat > 0.85:
        score -= 0.15

    # 亮度：避免过暗/过亮
    bright = visual_stats['brightness_mean']
    if 0.25 <= bright <= 0.75:
        score += 0.10
    elif bright < 0.10 or bright > 0.90:
        score -= 0.20

    # 边缘密度：有内容细节但不杂乱
    edge = visual_stats['edge_density']
    if 0.05 <= edge <= 0.25:
        score += 0.10
    elif edge > 0.40:  # 太杂乱
        score -= 0.10

    # 色彩丰富度：color_std 高=色彩丰富
    # 运动量：空镜适中运动最好
    motion = visual_stats['motion_score']
    if 0.02 <= motion <= 0.15:  # 缓慢推移
        score += 0.10
    elif motion > 0.40:  # 抖动严重
        score -= 0.15

    return max(0.0, min(1.0, score))
```

#### 维度三：叙事价值（20%）— 需新增

判断这个素材在视频叙事中的价值。

| 指标 | 计算方式 | 说明 |
|------|---------|------|
| 旁白伴随 | 是否有 ASR 文本覆盖该时间段 | 有旁白=有叙事推进作用 |
| 信息密度 | OCR文字 + ASR文本 + 画面物体数 | 信息越丰富，叙事价值越高 |
| 场景独特性 | 该场景类型在素材库中的出现频率 | 稀有场景更有价值 |
| 情感强度 | emotion_intensity 字段 | 强情感的空镜更有价值 |
| 过渡适用性 | 是否适合作为转场/过渡镜头 | 基于时长+运动+构图 |

**关键规则：** 一个空镜如果 **既没有美感（美感评分 < 0.4），又没有旁白推进剧情（无 ASR 覆盖且信息密度低）**，就是潜在的"垃圾素材"。

#### 维度四：音频质量（15%）— 已有基础

直接复用 `audio_quality.py` 的评分。

#### 维度五：独特性（10%）— 需新增

| 指标 | 计算方式 | 说明 |
|------|---------|------|
| 视觉去重 | pHash / 指纹相似度 | 与库中其他素材的视觉相似度 |
| 场景稀缺度 | 该场景类型的库存占比 | 占比越低越稀缺 |
| 时间独特性 | 拍摄时间段的稀缺度 | 独特时间段（如凌晨、黄昏）更有价值 |

### 3.3 垃圾素材识别规则

```
垃圾素材判定条件（建议删除）：
├── 条件 A：技术质量 < 0.3（严重模糊/低分辨率/严重抖动）
├── 条件 B：美感评分 < 0.3 AND 叙事价值 < 0.3（既不好看又没用）
├── 条件 C：综合评分 < 0.25（全方位低分）
├── 条件 D：与库中其他素材 pHash 相似度 > 0.95（几乎重复）
└── 条件 E：时长 < 1s AND 无特殊标记（残片）
```

### 3.4 用户呈现设计

```
素材卡片上的展示：

┌──────────────────────────────────┐
│ [缩略图]                          │
│                                  │
│ 综合评分: ⭐⭐⭐⭐ (82/100)        │
│ 技术: 85  美感: 78  叙事: 90      │
│ 音频: 75  独特: 80                │
│                                  │
│ 标签: #海边 #日落 #治愈 #空镜      │
│ 建议用途: 转场/氛围渲染            │
└──────────────────────────────────┘

对于垃圾素材：

┌──────────────────────────────────┐
│ [缩略图] ⚠️ 建议删除              │
│                                  │
│ 综合评分: ⭐ (18/100)             │
│ 原因: 画面模糊(0.2) + 无叙事价值   │
│                                  │
│ [删除] [保留] [重新评估]           │
└──────────────────────────────────┘
```

### 3.5 分级体系

| 等级 | 综合评分 | 标记 | 建议 |
|------|---------|------|------|
| S 精品 | ≥ 85 | 🌟 | 优先推荐使用 |
| A 优质 | 70-84 | ✅ | 推荐使用 |
| B 可用 | 50-69 | 📋 | 一般可用 |
| C 勉强 | 30-49 | ⚠️ | 谨慎使用，可能需要后期处理 |
| D 垃圾 | < 30 | 🗑️ | 建议删除 |

## 四、实现优先级建议

### Phase 1：关键词扩展（1-2 周）

1. **领域纵深扩展** — 手动 + LLM 辅助扩充每个大类到 50-80 词
2. **同义词扩展** — 引入同义词词林，批量生成别名
3. **组合关键词生成** — 在现有代码基础上增加 `_generate_composite_keywords()` 方法

**预期产出：** 关键词总量从 ~2K 扩展到 ~6K

### Phase 2：轻量美感评分（1 周）

1. 在 `video_asset_toolkit.py` 中新增 `aesthetic_score_lite()` 方法
2. 基于现有视觉统计数据的规则打分
3. 无需额外模型依赖

**预期产出：** 每个素材获得 0-1 的美感评分

### Phase 3：综合可用性评分 + 垃圾素材标记（1 周）

1. 实现五维综合评分
2. 实现垃圾素材判定规则
3. 在素材库 UI 中展示评分和建议

**预期产出：** 素材卡片展示评分，垃圾素材有明确标记

### Phase 4：关键词深度扩展 + NIMA 美学模型（2-3 周）

1. 垂直领域词库
2. 组合关键词生成优化
3. 引入 NIMA 预训练美学评估模型替代规则打分

**预期产出：** 关键词总量达到 10K+，美感评分更精准

## 五、风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 关键词膨胀导致搜索噪音增大 | 搜索准确率下降 | 设置质量阈值，低置信度词不进入搜索索引 |
| 美感评分过于主观 | 用户不认同评分 | 允许用户覆盖评分，收集反馈迭代 |
| 误标垃圾素材 | 有价值素材被建议删除 | 只"建议"不"自动删除"，用户确认后才删 |
| NIMA 模型体积大 | 桌面应用体积增加 | 先用轻量规则方案，NIMA 作为可选下载 |
| 组合关键词语义不通 | 产生无意义标签 | 通过 LLM 或人工审核过滤无意义组合 |

## 六、竞品对标

根据竞品分析报告，当前市场上：

- **语义关键词丰富度**方面，只有 Adobe Media Intelligence 和 Frame.io 在做深度语义标签，大多数竞品（Descript、CapCut、Opus Clip）的标签体系远不如本项目丰富。如果能达到万级关键词，将显著领先。
- **素材质量评估**是整个行业的空白。几乎没有竞品做到显式的素材质量评分+垃圾素材识别。这是一个明显的差异化机会。
- **B-roll 智能推荐**方面，InVideo 做了基于情感分析的 B-roll 匹配，但只针对股票素材库；本项目从用户自有素材库中推荐 B-roll，更加贴合用户需求。

---

## 七、总结

本方案围绕两个核心问题提出解决路径：

1. **关键词从 2K 扩展到 10K+**：通过领域纵深、组合生成、同义词扩展、垂类词库四条路径实现，分两个 Phase 落地。
2. **空镜/风景素材质量判断**：通过五维评估模型（技术+美感+叙事+音频+独特性）计算综合可用性评分，配合垃圾素材判定规则给出建议标记。

两个方案可并行推进，Phase 1-3 预计 3-4 周可初步完成。
