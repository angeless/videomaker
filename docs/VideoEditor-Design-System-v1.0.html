Design Principles

1. 注意力经济
每个页面只有一个主角。视频编辑器的核心区域是时间线和预览窗，其他面板为辅助。避免多个元素同时竞争视觉焦点。使用色彩层级（accent 强调 → text-secondary 降级）引导注意力流向。
2. 信息层级
3 秒内理解页面核心任务。标题用 --text-lg/semi，正文用 --text-md/regular，辅助用 --text-sm/tertiary。间距同样传递层级：同组元素用 --space-2，不同组用 --space-6。
3. 最少惊讶
交互行为可预期。所有按钮 hover 有 background 变化，所有输入框 focus 有 border-color 变化。拖拽操作始终有辅助线反馈。不使用会让用户困惑的隐式手势。
4. 渐进式披露
只在需要时展示复杂度。初始界面简洁（工作流 7 步只显示当前步骤详情），高级选项折叠在「更多设置」中。AI 分析结果先展示摘要，点击展开详情。
5. 即时反馈
每次操作都有回应。素材导入有进度条 + 百分比，AI 分析有 skeleton loading，导出完成有 toast 通知。长时间操作（>2s）必须有进度指示。
6. 容错设计
提供撤销而不只是确认弹窗。时间线操作支持 Ctrl+Z。删除素材后有 5s 的 undo toast。仅在不可逆操作（清空项目、删除原始文件）使用确认弹窗。
7. 一致性
同操作在所有页面行为一致。.btn-primary 永远是蓝色 (#5a8dee)，.badge-success 永远是绿色 (#34d399)。表单验证错误永远用红色边框 + 红色提示文字。
8. 留白即信息
间距是结构化手段，不是装饰。组件间用 --space-3 (12px) 表示「相关」，用 --space-8 (32px) 表示「不同组」，用 --space-16 (64px) 表示「不同 Section」。合理的留白比装饰性分隔线更有效。

Self-Check Checklist

点击可标记。开发新页面/组件时逐项自查。

注意力与层级

  • 页面是否有且只有一个视觉主角？
  • 3 秒内能否理解页面核心任务？
  • 标题 / 正文 / 辅助文字是否使用了正确的字号层级？

交互反馈

  • 所有按钮是否有 hover / active / disabled 状态？
  • 所有输入框是否有 focus 指示？
  • 长时间操作（>2s）是否有进度反馈？
  • 操作完成是否有 Toast 通知？

状态覆盖

  • 是否考虑了空状态（无数据）？
  • 是否考虑了加载状态（Skeleton）？
  • 是否考虑了错误状态？
  • 列表是否考虑了超长文本截断？

容错与安全

  • 不可逆操作是否有确认弹窗？
  • 可逆操作是否支持 Undo？
  • 表单提交是否有防重复点击？

一致性

  • 颜色是否全部使用 CSS Token 而非硬编码？
  • 间距是否全部使用 --space-* Token？
  • 相同语义的组件是否使用相同的样式？
  • 深色/浅色主题下是否都能正常显示？
确认操作
确定要开始渲染？这将使用当前时间线设置生成最终视频文件。
⚠️ 危险操作
确定要删除项目「加拿大旅行 Vlog」及其所有工作数据？此操作不可撤销。
